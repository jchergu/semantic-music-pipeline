8.1 — Batch, Reactive

An explicit "more like this" query against one seed track. Combines CLAP similarity, genre-sibling and same-artist signals into a ranked list.

8.2 — Streaming, Reactive

A listening session builds an implicit taste profile (a weighted CLAP centroid) as it plays. An on-demand query then reflects the whole session, not just one seed.

8.3 — Streaming, Proactive

Design-and-feasibility use case, given a minimal real vertical slice: while a track is currently playing, the system classifies it live (CLAP zero-shot) and proactively pushes a suggestion — unasked, over a WebSocket.
